# Parking Lot public road test

Play at https://romeojuliett.github.io/parking-lot-demo/ once the Pages deployment completes.

One starter car, the club lot, a local quarter-mile practice clock and three bounded county preview roads. The complete game is separate. This is an early desktop keyboard demo.

Controls: W/S or Up/Down to drive, A/D or Left/Right to steer, Space for the handbrake, M or Escape for the menu, R to return to the lot. Best times and settings stay in this browser. The menu provides road-test setup, Reduced motion and local data reset.

Third-party library and font notices are in `licenses/`. This repository contains only the compiled public demo and required notices; the game source and private distributions are separate.
